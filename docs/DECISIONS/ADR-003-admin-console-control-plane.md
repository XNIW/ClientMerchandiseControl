# ADR-003 — Admin Console come control plane

- Stato: ACCETTATA
- Data: 2026-07-29
- Task: TASK-001

## Decisione

Admin Console governa pubblicazione, copy pubblico, immagini, prezzi, promozioni,
disponibilità commerciale e fulfillment.

## Conseguenze

Il client è consumer del contratto pubblico, non editor del catalogo operativo.
